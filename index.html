1. Changing Case

6 methods

These change how letters are capitalised. None of them touch the original string, remember to reassign if you want to keep the result.

.upper()

Converts every letter to uppercase.

name = "data engineer"
print(name.upper())   # DATA ENGINEER
.lower()

Converts every letter to lowercase.

name = "DATA ENGINEER"
print(name.lower())   # data engineer
.capitalize()

Capitalises only the first letter of the whole string. Everything else goes lowercase.

title = "python FOR data ENGINEERING"
print(title.capitalize())   # Python for data engineering
.title()

Capitalises the first letter of every word.

heading = "python for data engineering"
print(heading.title())   # Python For Data Engineering
.swapcase()

Flips every uppercase letter to lowercase and every lowercase letter to uppercase.

mixed = "Hello World"
print(mixed.swapcase())   # hELLO wORLD
.casefold()

Similar to lower(), but more aggressive. Built for comparing text across different languages fairly.

word1 = "straße"
word2 = "strasse"
print(word1.casefold() == word2.casefold())   # True

2. Checking Content

12 methods

Every method here starts with "is" and returns True or False. They're your first line of defense before casting or processing a value, this is exactly the validation habit from the Module 2 deep dive, just the full toolkit.

.isalnum()

True if every character is a letter or a number, and there's at least one character.

print("Order123".isalnum())   # True
print("Order 123".isalnum())  # False - the space breaks it
.isalpha()

True only if every character is a letter, nothing else allowed.

print("Python".isalpha())    # True
print("Python3".isalpha())   # False
.isascii()

True if every character fits in standard ASCII, the basic English keyboard set.

print("Hello".isascii())     # True
print("héllo".isascii())     # False
.isdecimal()

The strictest number check. True only for plain decimal digits, 0 through 9.

print("123".isdecimal())     # True
print("12.3".isdecimal())    # False - the dot breaks it
.isdigit()

True for digits, and also a few special digit characters like superscripts.

print("123".isdigit())       # True
print("²3".isdigit())       # True - superscript still counts
.isidentifier()

True if the string could legally be used as a Python variable name.

print("batch_size".isidentifier())   # True
print("2nd_batch".isidentifier())    # False - can't start with a digit
.islower()

True if every cased letter in the string is lowercase.

print("data".islower())      # True
print("Data".islower())      # False
.isnumeric()

The broadest number check, covers digits plus number words and fractions in some scripts.

print("123".isnumeric())     # True
print("½".isnumeric())       # True
.isprintable()

True if every character can actually be displayed. False if there's a newline, tab, or similar hidden character.

print("Hello".isprintable())      # True
print("Hello\n".isprintable())    # False
.isspace()

True only if the string is made up entirely of whitespace.

print("   ".isspace())       # True
print("  a  ".isspace())     # False
.istitle()

True if the string already follows Title Case, first letter of every word capitalised.

print("Data Engineer".istitle())   # True
print("Data engineer".istitle())   # False
.isupper()

True if every cased letter in the string is uppercase.

print("DATA".isupper())      # True
print("Data".isupper())      # False

3. Searching & Counting

7 methods

These help you find things inside a string, or check how a string starts and ends, without writing a loop yourself.

.find()

Returns the index of the first match. Returns -1 if nothing's found, never crashes.

text = "customer_id"
print(text.find("_id"))     # 8
print(text.find("xyz"))     # -1
.rfind()

Same as find(), but searches from the right and returns the last match's index.

text = "data_2026_final_2026"
print(text.rfind("2026"))   # 17
.index()

Same as find(), but raises a ValueError instead of returning -1 when nothing matches.

text = "customer_id"
print(text.index("_id"))    # 8
.rindex()

Same as index(), but searches from the right.

text = "data_2026_final_2026"
print(text.rindex("2026"))  # 17
.count()

Counts how many times a substring appears.

text = "mississippi"
print(text.count("s"))      # 4
.startswith()

Checks whether a string begins with a given piece of text.

filename = "transactions_2026.csv"
print(filename.startswith("transactions"))   # True
.endswith()

Checks whether a string ends with a given piece of text. The clean way to check a file type.

filename = "transactions_2026.csv"
print(filename.endswith(".csv"))   # True

4. Trimming & Padding

8 methods

These clean up messy edges, or add extra characters to force a string to a specific width. Great for reports and fixed-width IDs.

.strip()

Removes whitespace, or specific characters you name, from both ends.

raw = "   Data Engineer   "
print(raw.strip())   # "Data Engineer"
.lstrip()

Removes whitespace (or named characters) from the left side only.

raw = "   Data Engineer"
print(raw.lstrip())   # "Data Engineer"
.rstrip()

Removes whitespace (or named characters) from the right side only.

raw = "Data Engineer   "
print(raw.rstrip())   # "Data Engineer"
.ljust()

Pads a string on the right with a filler character until it hits a target width. The text stays left-aligned.

code = "T1"
print(code.ljust(6, "0"))   # "T10000"
.rjust()

Pads a string on the left. The text stays right-aligned.

code = "T1"
print(code.rjust(6, "0"))   # "0000T1"
.center()

Pads on both sides to center the text inside a given width.

title = "REPORT"
print(title.center(20, "-"))   # -------REPORT-------
.zfill()

Pads a number-like string with leading zeros until it reaches a given length. Perfect for fixed-width codes.

branch_code = "7"
print(branch_code.zfill(4))   # "0007"
.expandtabs()

Replaces every tab character with spaces, useful for lining up plain-text tables neatly.

row = "id\tname\tamount"
print(row.expandtabs(10))

5. Splitting & Joining

6 methods

These break one string into several pieces, or glue several pieces back into one. This is how you'll parse almost every raw line of text you ever read.

.split()

Breaks a string into a list, using a separator. Default separator is any whitespace.

row = "T001,Aravind,4599"
print(row.split(","))   # ['T001', 'Aravind', '4599']
.rsplit()

Splits from the right. Useful when you want to control how many splits happen counting from the end.

path = "data/incoming/2026/file.csv"
print(path.rsplit("/", 1))   # ['data/incoming/2026', 'file.csv']
.splitlines()

Splits a multi-line string into a list, one item per line.

log = "Line 1\nLine 2\nLine 3"
print(log.splitlines())   # ['Line 1', 'Line 2', 'Line 3']
.partition()

Splits into exactly 3 parts on the first match: before, the separator itself, and after.

email = "ravi@intellibi.com"
print(email.partition("@"))   # ('ravi', '@', 'intellibi.com')
.rpartition()

Same as partition(), but splits on the last match instead of the first.

path = "data/incoming/file.csv"
print(path.rpartition("/"))   # ('data/incoming', '/', 'file.csv')
.join()

Glues a list of strings together, using this string as the separator between each piece.

columns = ["id", "name", "amount"]
print(",".join(columns))   # "id,name,amount"

6. Replacing & Modifying

5 methods

These change specific parts of a string, whether that's one substring, a whole set of characters at once, or a fixed prefix or suffix.

.replace()

Swaps every occurrence of one substring for another.

date = "2026-01-15"
print(date.replace("-", "/"))   # "2026/01/15"
.translate()

Replaces characters based on a translation table. Faster than chaining several replace() calls.

table = str.maketrans("aeiou", "12345")
text = "data engineer"
print(text.translate(table))   # "d1t1 2ng1n22r"
.maketrans()

Builds the translation table that translate() actually uses. Called on the str class itself, not an instance.

table = str.maketrans("ab", "12")
print(table)   # {97: 49, 98: 50}
.removeprefix()

Removes a piece of text from the start, only if it's actually there. Python 3.9 and above.

filename = "raw_transactions.csv"
print(filename.removeprefix("raw_"))   # "transactions.csv"
.removesuffix()

Removes a piece of text from the end, only if it's actually there. Python 3.9 and above.

filename = "transactions.csv"
print(filename.removesuffix(".csv"))   # "transactions"

7. Formatting

2 methods

These insert values into a template string. You already know f-strings from Module 2, these two are the older, still-common alternative.

.format()

Inserts values into placeholders inside a string, in the order you pass them.

template = "Pipeline {} processed {} rows"
print(template.format("orders_etl", 500))
# "Pipeline orders_etl processed 500 rows"
.format_map()

Like format(), but takes one dictionary directly instead of separate arguments.

data = {"pipeline": "orders_etl", "rows": 500}
template = "Pipeline {pipeline} processed {rows} rows"
print(template.format_map(data))

8. Encoding

1 method

Only one method here, but an important one. It converts readable text into bytes, the form data actually needs to be in before it travels over a network or gets saved in certain file formats.

.encode()

Converts a string into bytes, using the character encoding you specify.

text = "Hello"
print(text.encode("utf-8"))   # b'Hello'
